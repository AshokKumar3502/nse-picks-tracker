# NSE Picks Tracker

A public record of two lists made by an NSE research toolkit, and what each stock did afterwards:

- **Intraday**: the bullish names listed before the 9:15 AM open, for that day, scored by one fixed breakout rule after charges.
- **Swing**: the bullish names listed after the close, for 2 to 5 days, with the move after 1, 2 and 5 sessions.

Each list shows the date and time it was made. The data (`data/picks.json`) is refreshed every weekday evening from NSE's own end-of-day files.

Past results, not predictions. Not financial advice.
